Antigravity 新手攻略與必學秘訣

把 Antigravity 當成「能直接動手幫你做事的 AI 同事」，而不是只會聊天的問答機器人。這份手冊整理了最核心的操作心法、必學斜線指令（Slash Commands）、常用快捷鍵與新手最容易踩的 8 個地雷。

1. 先搞懂你面前的三大介面

新手第一步

🖥️ Antigravity 2.0 桌面版

最推薦新手起步的「AI 任務指揮中心」，適合整理文件、跑自動化與多任務管理。

  • 左側欄：管理 Projects（工作區）、Scheduled Tasks（定時任務）、Skills & Customizations 與 Settings。
  • 中間對話畫布：支援 / 指令、@ 引用檔案、直接拖放圖片或文件。
  • 輔助面板：即時查看子代理、背景任務、Artifacts 產出與終端機狀態。

🧩 Antigravity IDE

內建於 VS Code 體驗的 AI 原生開發環境，寫程式、改文件與看 Diff 差異最強。

  • Antigravity Tab：隨打字自動預測下一行甚至整段修改（按 Tab 接受）。
  • Inline Command：按 Ctrl+I（Mac 為 ⌘+I）只改選取的那幾行。
  • Sidebar Agent：能改多檔、跑測試、查看紅綠 Visual Diff 再決定要不要套用。

⌨️ Antigravity CLI（agy）

在終端機裡一秒召喚 AI 的極速文字介面，適合老手與伺服器／腳本工作。

  • 在終端機輸入 agy 直接開啟互動介面。
  • 輸入 agy --help 看命令列參數；進入後輸入 /help 看所有指令。
  • 設定檔位於 ~/.gemini/antigravity-cli/settings.json；離開按 Ctrl+D 兩次或 /exit。

2. 讓 AI 一次做對的 4 大黃金心法

80/20 法則

📁 心法 1：先開對 Project（工作區）再發問

Antigravity 是「圍繞資料夾工作」的。先在左側切換到對的專案資料夾，它才會優先讀取該資料夾的檔案與專屬規則。

秘訣 在 Settings 中，Project-Level Settings（專案設定）優先於 Global Settings（全域設定），重要資料夾可單獨鎖緊安全權限。

🎯 心法 2：用 @ 指名道姓 + 拖放截圖

不要只說「改一下剛剛那個檔案」。在對話框輸入 @ 可以直接點名檔案、資料夾、歷史對話、終端機輸出或規則，精準度立刻翻倍。

秘訣 遇到畫面報錯、表格截圖或設計草圖，直接把圖片拖進聊天框，AI 會一起看圖判讀。

🧭 心法 3：複雜任務「先對齊、再動手」

最浪費時間的用法，就是一句模糊的話讓 AI 跑 5 分鐘最後產出完全不是你要的東西。複雜任務先用 /grill-me 或 /plan 確認方向。

秘訣 在 IDE 中也可以切換成 Planning Mode（規劃模式），先審核步驟清單再讓它寫檔。

🛡️ 心法 4：看懂 4 種權限安全檔位

在 Settings → Tool Execution Policy 中決定 AI 執行指令前要不要問你，兼顧效率與安全：

  • request-review（推薦新手）：改動或跑指令前先給你看過再放行。
  • proceed-in-sandbox：在隔離沙盒環境內自動跑，最安全又省心。
  • strict：最高戒備，嚴格把關每個敏感動作。
  • always-proceed：全自動放行，僅建議用於可隨時還原的練習環境。

3. 必學斜線指令（Slash Commands）實戰庫

輸入 / 直接召喚 · 支援雙軌切換
怎麼用最順手？ 只要在對話框輸入 / 就會跳出選單。點擊下方每張卡片右上角的「日常辦公」或「程式開發」標籤，即可切換範例並一鍵複製可直接套用的 Prompt！

/grill-me 需求還很模糊？叫 AI 先來問倒你

AI 會化身專業顧問，一次一題把你的目標、對象、格式與限制條件問清楚，避免做白工。

/grill-me 我想整理這個月部門的會議紀錄和待辦追蹤表，做成一份給主管看的週報，但我還沒想好呈現格式。
/grill-me 我想為目前的專案加上使用者登入與權限管理，請先訪談確認架構、資料庫與安全性需求，再開始動手。

/plan 任務步驟很多？先寫出施工藍圖

強迫 AI 在動手改檔案前先列出完整步驟、會動到哪些檔案、以及預期結果，讓你先點頭再執行。

/plan 請先規劃怎麼把 @報表資料夾 裡這 12 份 CSV 合併成一份總表、抓出異常值並產出摘要報告，確認步驟後再執行。
/plan 請分析 @src/api/ 並規劃把舊版同步查詢重構為非同步與快取機制的完整步驟，先給我修改清單與風險評估。

/browser 需要操作網頁、查動態頁面或填表？交給瀏覽器代理

內建瀏覽器子代理會真的開網頁點擊、捲動、抓畫面或驗證前端操作，比純文字搜尋更可靠。

/browser 請幫我打開這三間廠商的官網定價頁面，截圖並整理成一份方案價格與功能比較表。
/browser 請打開本機預覽網址 http://localhost:3000，實際測試登入表單、送出按鈕與手機版面是否有跑版。

/schedule 固定要做的事？設成背景自動排程

設定一次性的定時提醒，或每天／每週自動執行的背景任務，並可在左側 Scheduled Tasks 統一管理。

/schedule 每個星期五下午 4 點自動檢查 @工作筆記 資料夾這週新增的內容，幫我彙整成下週一早會的 5 點摘要。
/schedule 每天早上 9 點自動檢查 @logs/error.log 是否有新的例外錯誤，若有異常請整理成問題清單通知我。

/learn 糾正過一次的事，永久教會它

當你發現自己第二次提醒同一件事（語氣、格式、命名規範、常用路徑），馬上用 /learn 寫成永久規則或技能。

/learn 以後凡是幫我整理會議紀錄，一律使用「決議事項 / 負責人 / 預計完成日」三欄表格，且不要省略原始數據單位。
/learn 請把剛才修復 Windows PowerShell 編碼與虛擬環境啟動的正確指令記錄成專案規則，以後跑測試一律照此執行。

/compact 對話聊太長變鈍了？一鍵瘦身不失憶

對話太長會塞滿上下文視窗導致遺忘前面的要求；/compact 會濃縮關鍵脈絡、清出空間繼續衝刺。

/compact 請保留目前定案的報告架構與所有真實數據結論，把前面反覆討論修改的草稿過程壓縮摘要。
/compact 請保留已確認的架構決策、修改過的檔案路徑與測試指令，壓縮前面的除錯試誤紀錄。

/goal · /teamwork · /boost 三大重火力進階指令

/goal 適合長時徹底執行不半途停手；/teamwork 適合派多個專家子代理分頭並進；/boost 適合高難度推理與嚴格驗證。

/teamwork 請把這份 50 頁市場調查報告分組處理：一組負責提煉數據圖表重點、一組負責整理競品優劣比較、最後由你統整成一份高階簡報大綱。
/boost 請深入排查 @src/checkout/ 在高並發下出現重複扣款的根本原因，從資料庫鎖、交易邊界到重試機制完整驗證並補齊測試。

4. IDE 快捷鍵與 CLI 加速秘訣

效率翻倍
操作 / 快捷鍵 所在介面 實戰用途與新手秘訣
Tab / Esc Antigravity IDE 接受或取消 AI 的自動補全、Supercomplete 修改建議，以及 Tab to Jump（自動跳到下一個該改的位置）與 Tab to Import。
Ctrl+→（Mac：⌘+→） Antigravity IDE 不想整段全收時，用這個鍵「逐字／逐詞」局部接受 AI 建議，掌控感最好。
Ctrl+I（Mac：⌘+I） Antigravity IDE 行內指令（Inline Command）：反白一段程式或文字直接微調、加註解或重構，不會亂動到其他地方。
Visual Diff & Auto-Fix Antigravity IDE 所有修改都會顯示紅綠差異比對；看到錯誤波浪線或 Problems 面板報錯時，可直接點 Diagnostic Auto-Fix 讓 AI 自動修復。
agy / /help 終端機（CLI） 直接開啟輕量文字模式問問題或跑任務；查詢指令打 /help，安全離開按 Ctrl+D 兩次或輸入 /exit。

5. 讓 AI 越用越懂你的四大擴充機制

打造專屬助手

📜 Rules（永久行為準則）

設定檔：GEMINI.md、AGENTS.md、.agents/rules/*.md

用來規定 AI 永遠該遵守的原則（例如：回答語言、排版格式、禁止修改特定檔案、程式碼風格）。

🧰 Skills（按需載入技能包）

設定檔：skills/<名稱>/SKILL.md

把標準作業流程（SOP）教給 AI。平時只載入名稱與簡介，真正用到才展開全文，完全不浪費對話空間。

🔌 Plugins & MCP Servers

設定檔：plugins/<名稱>/plugin.json、mcp_config.json

一鍵幫 Antigravity 裝上外部工具（雲端文件、資料庫、設計工具、開發框架），不用自己寫串接程式。

📂 規則存放優先順序（從高到低）

  • 1. 專案工作區：目前資料夾內的 .agents/、GEMINI.md（最高優先）
  • 2. 全域個人設定：本機 ~/.gemini/config/（套用到所有專案）
  • 3. 系統內建技能：Antigravity 原生內建能力

6. 新手最常踩的 8 大地雷與排雷解法

點擊展開對策
❌ 新手地雷在同一個對話裡先問報表、接著聊旅遊、又回來改程式，上下文塞滿雜訊。
✅ 高手解法一件任務開一個 New Conversation；同一件長任務聊太久，先下 /compact 濃縮脈絡再繼續。
❌ 新手地雷留在空工作區或上層根目錄直接說「改一下我的簡報／專案」。
✅ 高手解法先在左側 Projects 切換到正確資料夾，並善用 @檔名 精準指定目標檔案。
❌ 新手地雷只給目標不給標準：「幫我整理這份文件並做得專業一點。」
✅ 高手解法先下 /grill-me 讓 AI 問清楚你的標準，或用 /plan 先確認步驟與輸出格式。
❌ 新手地雷直接把權限開成 always-proceed 也不做版本備份。
✅ 高手解法保留 request-review 或 proceed-in-sandbox，重要專案搭配 Git 與 IDE 的紅綠 Diff 檢視再套用。
❌ 新手地雷叫終端機用 curl 硬抓需要 JavaScript 渲染或互動點擊的網站。
✅ 高手解法直接輸入 /browser 交給內建瀏覽器代理操作；遇登入或驗證畫面時自己登入後再讓它接手。
❌ 新手地雷每次都重打一遍：「請用繁體中文、條列式、不要刪我原本註解…」
✅ 高手解法講過一次覺得好用，立刻下 /learn 或寫進 GEMINI.md／Rules，從此全自動遵守。
❌ 新手地雷一次丟 20 個檔案要求同一輪對話直接全部改完又做測試。
✅ 高手解法改用 /plan 拆階段，或用 /teamwork 派多個子代理分頭並進、交叉檢查。
❌ 新手地雷每週五固定手動開檔案整理週報或巡檢記錄。
✅ 高手解法用 /schedule 設定定期自動執行，把例行工交給背景排程。
